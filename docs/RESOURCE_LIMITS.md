# 公共共享资源限制

工具不需要注册账号。Local 未开启共享时不建立 WebSocket；Remote 只在点击“申请连接”后建立连接，取消、撤销或共享端离线后释放连接。Local 停止共享会释放连接并保留本机串口。

服务端使用内存中的资源预算限制匿名使用，不根据共享码识别人员。串口审批和只读限制继续执行；多个可发送端与本机统一排队，五位共享码仍是定位符。

## 默认值与配置

所有值必须为正数。默认值用于小规模部署，可通过启动参数调整；这些值不是已验证的并发容量。

| 参数 | 默认值 | 含义 |
| --- | ---: | --- |
| `-max-connections` | 64 | 同时存在的 WebSocket 连接预留数 |
| `-max-connections-per-ip` | 8 | 每个来源 IP 的并发连接数 |
| `-connections-per-minute` | 20 | 每 IP 的新连接尝试；注册/共享码申请另有同值预算，均跨连接保留 |
| `-http-requests-per-minute` | 120 | 每 IP 的 HTTP 请求速率，突发额度为 120 次 |
| `-messages-per-second` | 2000 | 每连接及每 IP 的 WebSocket 消息速率，突发 4000 条；全局为该值的 4 倍 |
| `-client-bytes-per-second` | 524288 | 每来源 IP、每源连接的应用字节速率，突发为 2 秒额度 |
| `-global-bytes-per-second` | 2097152 | 全服务应用字节速率，突发为 2 秒额度 |
| `-daily-transfer-bytes` | 2147483648 | 每 UTC 日的中继/下载采样预算，2 GiB |
| `-max-queued-bytes` | 262144 | 每连接发送队列最多 256 KiB，同时保留 256 帧上限 |
| Local RX 补传上传速率 | 128 KiB/s，突发 32 KiB | Local 对补传 WebSocket 消息限速，降低触发每连接/每来源字节预算的概率 |
| RX 补传实时队列 | 192 KiB / Remote | 补传期间暂存的实时字节上限；超限断开该 Remote，不静默丢弃 |

HTTP 另有固定的全局每秒 100 次、突发 200 次请求预算。来源 IP 状态最多 4096 项，无连接且 5 分钟未使用的项会回收；状态表满时拒绝新来源，不扩张内存。共享码申请、消息和字节预算保留在 IP 状态中，换 WebSocket 不会重置同一 IP 的预算。共享出口/NAT 下的使用者共用 IP 额度。

应用字节预算按 WebSocket 有效载荷（包含 JSON/Base64）和 HTTP 响应体预留。入站消息先计费再解析；普通中转多 Remote 数据转发按副本数一次预留。串口 P2P 的接收元数据与混合中转分别预留各副本，预算不足会关闭源共享，先前入队的副本可能已发出。Ping/Pong 同样受消息速率约束。静态页面/资源受请求与字节速率限制，但不占每日中继预算，因此每日中继额度用尽后仍可打开本机工具。

串口 P2P 的直连字节不经过服务器，也不计入上述中继字节额度；信令、逐条 TX 摘要许可、RX head 和 WSS 补传继续计量。有任一中转或未决审批时，Local 仍向服务器上传 RX 载荷，服务器跳过已经直连的目标副本。直连发送另有浏览器端有界队列和背压，详见 PROTOCOL.md；这些限制不提供付费权益或直连吞吐计费。

“评估网络”在未直连时使用原 HTTP 采样预算；直连时的独立探测不经过服务器字节计量。P2P 每轮有效样本 128 KiB、含控制/帧头总预算 144 KiB、最多 20 秒；每页同时一个、启动间隔至少 30 秒、发送缓冲最多 8 KiB。双方仍须保有当前批准关系，探测不进入串口或串口计数；这些是浏览器端资源边界，不是服务端计费额度。

同源 ICE 配置脚本受普通 HTTP 预算约束，不接受客户端覆盖。STUN 服务属于部署基础设施，不计入 Go 中继计数，应独立限制资源；预览的 STUN-only 实例只监听 UDP 18444，禁用 TURN/TCP/TLS/DTLS/管理 CLI，并设独立 CPU/内存及内核每来源和全局包速率边界。

Remote ESP32 固件镜像通过普通 WebSocket 串口数据帧转发，适用同一每连接、每 IP、全局速率与每日中继预算；按 Base64/JSON 后的有效载荷计量。服务器不将镜像作为文件写盘，也不为固件提供绕过限额的上传通道。大镜像会占用共享带宽与每日中继额度，达到限制时烧录会失败并释放串口会话。

每日额度使用 UTC 日界，在进程重启后归零；取消的排队输出仍可能占用已预留额度。它不是云厂商计费流量上限，不包含 TLS、TCP、HTTP 头和错误响应等全部网络开销。实际应用流量计数与预留预算分开记录。

## 反向代理

默认不信任 `X-Forwarded-For`，直接按 TCP 对端限额。使用本机 Caddy 等代理时显式指定：

```sh
./shareserial -addr 127.0.0.1:12445 -cert /path/cert.pem -key /path/key.pem \
  -trusted-proxies=127.0.0.1/32,::1/128
```

代理需要覆盖来源转发头并保留原 Host，以保持 IP 限额和 WebSocket 同源检查正确。只信任实际代理的地址；错误地信任任意来源会允许伪造 IP 绕过限额。

## 超限与恢复

HTTP 请求/容量/采样预算超限返回 429、固定错误码和 `Retry-After: 60`；每日额度须等下个 UTC 日，60 秒并不承诺该时恢复。响应体在发送前完整预留，拒绝不会截断正常的 200 响应。

已建立的 WebSocket 超限时，Hub 清理注册、待批准申请与授权，单一写入协程发送错误并以 4008 关闭。原因包括 `message_rate_limited`、`connection_rate_limited`、`bandwidth_limited`、`daily_quota_exceeded`、`send_queue_limited`。终止通知有一个有界的小响应，不依赖已耗尽的业务预算。慢连接或网络写入失败可能无法收到通知。

Local 收到资源错误立即停止共享、关闭自动接受、清除远端权限，已排队的写入重新检查授权；已进入驱动的在途字节不能撤回。本机串口保持打开，用户可降低负载后手动重新共享。Remote 显示原因并释放连接，需要重新申请。没有自动重放、隐式降速或静默丢弃后继续串口会话。

普通网络异常时，Local 从 3 秒开始退避重连，最多间隔 30 秒；注册成功后重置。Remote 需要用户点击重新申请，不在后台无限建立空闲连接。

## 使用量日志

每分钟输出 `event=resource_usage`，包含活动连接数、IP 状态数、WebSocket 输入/成功输出有效载荷字节、HTTP 输出体字节、当日预留额度及拒绝次数。`event=resource_limit` 关联已有连接诊断编号与错误码。新增日志不记录串口内容或 IP 明细，计数在重启后归零；没有公开统计接口或第三方遥测。

这些限制用于控制基本资源消耗，不提供人员认证、公平的按人配额或网络层攻击防护。真实硬件和持续压力验收仍见 ROADMAP.md。
